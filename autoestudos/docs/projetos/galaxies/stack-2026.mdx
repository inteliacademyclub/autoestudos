# Stack 2026: Ferramentas, Versões e o que Mudou

O briefing recomenda ferramentas, mas **nada é obrigatório**: a escolha precisa ser justificada no README. Esta página traz uma combinação **testada em conjunto** em setembro de 2026 e as mudanças recentes que podem quebrar o seu código se você seguir um tutorial antigo.

:::info[Verificado em 27/09/2026]
As versões abaixo foram instaladas e resolvidas juntas num ambiente Python 3.12. Bibliotecas de IA mudam rápido, então **fixe as versões** no seu `pyproject.toml` e anote no README.
:::

## Ambiente completo

```bash
uv init galaxies-agente --python 3.12 && cd galaxies-agente

# dados e modelo
uv add pandas==3.0.6 numpy==2.5.3 scipy==1.18.1 pyarrow==25.0.1 duckdb==1.5.5 \
       scikit-learn==1.9.1 lightgbm==4.7.0 catboost==1.2.10 xgboost==3.4.1 \
       optuna==5.0.0 shap==0.52.0 mapie==1.5.0 mlflow==3.16.1 \
       pydantic==2.13.5 pandera==0.33.1 pytest

# coleta
uv add google-api-python-client==2.200.0 isodate==0.7.2 tenacity==9.1.4 httpx==0.28.1

# multimodal (em Colab/Kaggle com GPU, se possível)
uv add torch==2.14.0 transformers==5.17.0 sentence-transformers==6.1.0 \
       opencv-python-headless==5.0.0.93 scenedetect==0.7.1 faster-whisper==1.2.1 \
       librosa==1.0.0 "yt-dlp[default]==2026.8.19" google-genai==2.25.0

# agente e integração
uv add langgraph==1.2.12 langchain==1.4.2 langchain-core==1.6.5 \
       langchain-mcp-adapters==0.3.2 fastmcp==3.4.7 mcp==1.30.0 faiss-cpu==1.15.1
```

:::danger[A pegadinha do MCP]
`langchain-mcp-adapters 0.3.2` exige **`mcp<2`**. Por isso a combinação que funciona num ambiente só é **`fastmcp==3.4.7` + `mcp==1.30.0`**.

Existem versões mais novas, mas elas são incompatíveis com o adapter:
- **FastMCP 4.x** (ago/2026);
- **SDK oficial `mcp` 2.x**, em que a classe `FastMCP` virou `MCPServer` e **não há alias**, então `from mcp.server.fastmcp import FastMCP` quebra.

Se quiser usá-las, rode o servidor MCP num ambiente separado do agente. Detalhes na aula [MCP do zero](/aulas/ml-preditivo-e-agentes/agente-preditivo-e-mcp/mcp-do-zero).

Sobre o protocolo: a revisão **2026-07-28** da spec do MCP é *stateless*. Ela remove o `initialize`, leva versão e capacidades no `_meta` de cada mensagem e cria o `server/discover`. O `mcp` 1.30 ainda fala a versão `2025-11-25` com handshake, e os clientes atuais negociam essa versão sem problema.
:::

## O que mudou desde o briefing

| Tema | O briefing diz | Em set/2026 |
| :--- | :--- | :--- |
| **Base de dados** | Entregue pela liga no kickoff | **Cada aluno monta a sua** ([guia](/projetos/galaxies/monte-sua-base)) |
| **VLM local** | Qwen2.5-VL 3B/7B | **Qwen3-VL** (2B/4B/8B) e **Gemma 4** (Apache-2.0, com vídeo) são as opções atuais. Qwen2.5-VL ainda funciona |
| **Gemini** | "Gemini Flash-Lite free tier (~1.000 req/dia)" | Modelos 3.x (`gemini-3.5-flash-lite`). O 2.0 Flash foi desligado em 01/06/2026. Limites do free tier só no AI Studio. **Aceita URL do YouTube direto** |
| **Leitura de frames** | ffmpeg ou decord | **decord está abandonado**: use OpenCV, ffmpeg/PyAV ou torchcodec |
| **MediaPipe** | MediaPipe | **`mp.solutions` removido**: Tasks API |
| **PySceneDetect** | PySceneDetect | 0.7 mudou a API de timestamps |
| **yt-dlp** | Manter atualizado, cookies, sleep | Agora exige **runtime JS (Deno)**. PO tokens em clientes web |
| **YouTube API** | search = 100 unidades | `search.list` tem **balde próprio de 100 chamadas/dia** (jun/2026). Novo `videos.batchGetStats` (03/06/2026, balde próprio). Nova seção III.L das políticas sobre métricas derivadas |
| **Views como alvo** | curtidas ou views | A contagem de views de Shorts mudou em **31/03/2025** e de novo em **24/08/2026**: quebras de regime. **Prefira curtidas** |
| **Agente** | LangGraph + LangChain | LangGraph 1.x: `create_react_agent` descontinuado → `create_agent` |
| **MCP** | FastMCP | Três "FastMCP" no mercado. Use **FastMCP 3.4.7 + mcp 1.30** com o adapter (veja acima) |
| **SHAP** | SHAP | 0.52 exige **Python ≥ 3.12** |
| **MAPIE** | MAPIE | API 1.x nova. O split helper é aleatório |
| **Papers** | HyperFusion "vencedor de 2025" | HyperFusion é da trilha de **imagem**. O vencedor de vídeo em 2025 é o MVP. Já existe o **SMP 2026** (vídeo: MAPE 0,1529). Veja as [leituras](/projetos/galaxies/leituras) |
