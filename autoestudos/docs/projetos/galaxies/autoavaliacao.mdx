# Autoavaliação dos Entregáveis

Use esta página para conferir o projeto antes de entregar. Os itens seguem os entregáveis do briefing e estão divididos em **núcleo** (obrigatório) e **ir além**. O progresso fica salvo no seu navegador.

:::info[Três camadas de ambição do multimodal]
| Camada | O que inclui | Custo |
| :--- | :--- | :--- |
| **1 · Mínima (obrigatória)** | Frames + SigLIP/CLIP + faster-whisper + OCR/rosto/objetos + métricas OpenCV + PySceneDetect, tudo concatenado a metadados e histórico no GBM | Zero, 100% offline (Colab grátis) |
| **2 · Recomendada** | Camada 1 + VLM respondendo a rubrica em JSON + clusterização dos descritores | Zero no free tier; fallback em modelo local |
| **3 · Ambiciosa** | Camada 2 + X-CLIP/VideoMAE, fusão thumbnail + gancho, retrieval com FAISS, ensemble | Tempo de GPU (Kaggle) |
:::

:::tip[O que costuma diferenciar os melhores projetos]
- **Avaliação honesta:** split temporal, sem vazamento, com o otimismo do CV aleatório medido e explicado.
- **Resultados com intervalo de confiança** em vez de um número solto.
- **Uma análise de erros com exemplos concretos** ("o modelo superestima vídeos longos de canais pequenos").
- **Explicação que não inventa:** validada contra o JSON do modelo.
- **README que qualquer pessoa consegue rodar do zero.**
:::
