# Laboratório de Interativos

Todas as simulações da trilha num só lugar, para revisar um conceito rapidamente. Cada uma também aparece na aula correspondente, que dá o contexto completo.

:::info[Sobre os dados]
Os componentes marcados com **dados simulados** usam um gerador de canais e Shorts com **efeitos conhecidos**: gancho, rosto, texto na tela, energia da música, duração, horário e uma tendência própria de cada canal. Os números são realistas na forma, mas **não são dados reais**. A vantagem de conhecer a "verdade" é poder mostrar, por exemplo, quando uma validação é otimista ou se uma explicação recupera o efeito real.
:::
