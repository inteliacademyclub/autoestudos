# Leituras Comentadas

Você não precisa ler todos os papers de ponta a ponta. Para cada um, esta página diz **o que ele faz, quais números importam, o que aproveitar no seu projeto e onde desconfiar**. Ler um paper com senso crítico também é um entregável: no README, você vai comparar seus números com a literatura.

:::tip[Como ler um paper de predição de popularidade em 15 minutos]
1. **Qual é o alvo?** Views, curtidas, uma razão, uma faixa? Normalizado por dias?
2. **Como foi o split?** Aleatório, temporal, por usuário/canal?
3. **O que já se sabia antes da publicação** e o que entrou como feature?
4. **Qual é o baseline** e quanto o método ganhou sobre ele?
5. **Dá para reproduzir?** Há código e dados públicos?
:::

## Os trabalhos mais próximos do case

<PaperCard
  titulo="Understanding Virality: A Rubric-based VLM Framework for Short-Form Edutainment Evaluation"
  referencia="Gupta et al., arXiv:2512.21402, 2025"
  link="https://arxiv.org/abs/2512.21402"
  resumo="O trabalho mais parecido com o case. Em 11 mil YouTube Shorts educativos, o Gemini extrai os 5 principais elementos de áudio e de vídeo de cada Short. Esses descritores são embedados (all-mpnet-base-v2), agrupados com K-Means em 20 clusters e, junto com metadados, alimentam um XGBoost. O SHAP explica o resultado."
  numeros={['Spearman 0,71', 'par-a-par 76,3%', 'R² 0,61', 'energia de áudio: 12,4% do SHAP', 'movimento: 10,7%', 'cortes: 7,6%']}
  usar={[
    'A rubrica via VLM + clusterização de descritores como features (aula 4.8).',
    'A lista de atributos com evidência: energia de áudio, movimento, contraste texto × fala, cortes.',
    'O teste fora do domínio (Instagram Reels: 64% par-a-par) como ideia de avaliação de generalização.',
  ]}
  criticar={[
    '**Split aleatório** (70/15/15), não temporal: os números podem estar otimistas (aula 2.3).',
    'O alvo é a razão curtidas/views, que usa uma métrica pós-publicação no denominador. Não serve como alvo "antes de publicar" sem adaptação.',
    'Sem código nem dados liberados; domínio educativo, não moda, beleza ou automotivo.',
  ]}
/>
